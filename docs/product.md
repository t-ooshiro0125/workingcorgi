# Working Corgi

## 目的

自己紹介、制作物、技術記事を公開する個人サイトを作る。軽量で読みやすく、GitHub Pages から静的に配信できることを重視する。

## 初期リリース

- Home: 自己紹介の要約と各ページへの入口
- About: 経歴、得意分野、プロフィール
- Works: 制作物の紹介
- Notes: 技術記事、気が向いたときに書く記事、Development Log の一覧と個別ページ
- GitHub や SNS など、外部プロフィールへのリンク

## デザイン方針

- 落ち着きがあり、余白を活かしたシンプルなデザインにする。
- 背景は温かいオフホワイト、文字は濃いチャコールを基本にする。
- セージ、マスタード、テラコッタ系のくすんだ色を控えめな差し色に使う。
- コーギーのオリジナルイラスト、マーク、肉球を少量だけ使い、やさしい遊び心を加える。
- Home には作業中のコーギーのイラスト、About にはアバターを置く。肉球は全ページ共通の控えめな背景装飾にする。
- 特定作品のキャラクターやロゴを使わず、温かく親しみやすい空気感を目指す。

## コンテンツの方針

- Notes は Markdown と Astro Content Collections で管理できる構成にする。
- Notes は `tech`、`note`、`devlog` のカテゴリで区別する。
- Notes には、GitHub Discussions を保存先とする giscus のコメント欄を設ける。
- 公開日時、更新日時、タイトル、概要、カテゴリを用意し、一覧で探しやすくする。
- 日本語を基本とし、多言語化は必要になった時点で設計する。
